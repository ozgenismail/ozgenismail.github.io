Privacy Policy

Ismail Saglik Asistani is a private tool used by a single person, its owner. It has no other users.

Data accessed

With the owner's consent, the tool has read-only access to the owner's own Google Health data types that the owner authorizes, such as activity and fitness, health metrics and measurements, sleep and nutrition. It cannot write, change or delete any Google Health data.

How the data is used

The data is used only to answer the owner's own questions about their health, diet and exercise. It is not used for advertising, is not sold, and is not used for credit decisions or any other purpose.

Storage

Data is stored only on the owner's own computer, on an encrypted drive. OAuth tokens are stored encrypted in the operating system's credential store.

Sharing

When the owner asks a question in Claude Desktop, the relevant data is sent to Anthropic's Claude only to produce the answer for the owner. The data is not shared with anyone else.

Deletion and revocation

The owner can revoke access at any time at https://myaccount.google.com/connections and can delete the locally stored data at any time.

Limited Use

The use of information received from the Google Health API will adhere to the Google Health API Developer and User Data Policy, including the Limited Use requirements.
